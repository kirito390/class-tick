# 课刻 ClassTick · 安装与部署指南

> 目标：**电脑上装成桌面应用 + 桌面上常驻小组件窗口 + 手机上添加到主屏幕**，并让提醒真正可靠。
>
> 当前默认皮肤是「皇室典藏」；打开课刻 →「御前设置 → 外观与关于 → 皮肤」可以切回「学院纸感」。
> 皇室素材（城堡主视觉、羊皮纸、金线角花、蜡封、纹章图标）都是本地文件，不依赖网络。
> 左下角的 Q 版头像就是**皇家导师艾莉丝**：点开可以对话，她可以直接改提醒时间、切换主题/皮肤、导出日历、打开签到入口，右上角 ✦ 还能换装。完整指令表见 [`royal-tutor.md`](royal-tutor.md)。
> 想要更自由的对话时，可以在「御前设置 → AI 对话（可选）」填入任意 OpenAI 兼容接口（默认 DeepSeek），关闭时完全本地解析。

## 一、电脑端（Windows，最快路径）

### 1. 准备 Node.js
课刻的本地服务只用到 Node 自带的模块，不需要 `npm install`。检查是否已装：

```powershell
node -v
```

没反应的话去 <https://nodejs.org/> 下载 LTS 版本安装（一路下一步即可）。

### 2. 启动
双击 **`启动课刻.cmd`**。脚本会：
1. 检查 8788 端口是否已有课刻在跑；
2. 没有就后台启动 `node server.mjs 8788`（最小化窗口）；
3. 打开 <http://127.0.0.1:8788/>。

> 为什么一定要用这个本地服务而不是直接双击 `index.html`？
> 因为浏览器把 `http://localhost` 当作**安全上下文**，只有在这种环境下 Service Worker、系统通知、PWA 安装才可用；直接打开 `file://` 会退化成普通网页（单文件版可以离线看课表，但装不了）。

### 3. 安装成桌面应用
- **Edge**：地址栏右侧「安装」图标，或 `…` 菜单 → 应用 → 安装此站点为应用
- **Chrome**：地址栏右侧「安装」图标
- 安装后可以：固定到任务栏 / 开始菜单、设置开机自启（Windows 设置 → 应用 → 启动）
- 课刻窗口本身也可以直接拉成窄条，充当「桌面小组件」

### 4. 小组件窗口（推荐）
双击 **`课刻-小组件.cmd`**：用 Edge/Chrome 的 `--app` 模式打开 `?widget=1` 的紧凑版，420×820，自动靠屏幕右侧。

- 想要开机自动出现：双击 **`课刻-开机自启.cmd`**（会在启动文件夹放一个快捷方式；取消用 `课刻-取消开机自启.cmd`）
- 想换位置：直接拖动窗口，Windows 会记住窗口位置
- 想更「小组件」：Windows 设置 → 个性化 → 任务栏 → 打开「使用小任务栏按钮」并把它放在角落

### 5. 打开通知权限
课刻右上角「开启提醒」→ 浏览器弹窗点「允许」。
之后可以点「设置 → 系统通知 → 发送一条测试通知」验证。

> 如果之前误点了「阻止」：点地址栏左侧的锁/站点信息图标 → 通知 → 允许 → 刷新页面。

### 6. 停止 / 重启
- 停止：双击 `课刻-停止服务.cmd`
- 重启：再双击 `启动课刻.cmd`（脚本会自动判断是否已经在跑）

## 二、手机端

### 方案 A：单文件版（最省事，离线可用）
1. 找到 `dist/课刻-手机版.html`（约 1.7 MB，已内联全部皇室素材、导师立绘与礼服）
2. 传到手机：微信「文件传输助手」发给自己 → 手机上打开；或数据线拷贝
3. 用手机浏览器打开这个文件
4. **安卓 Chrome**：右上角 `⋮` → 「添加到主屏幕」
   **iPhone Safari**：底部「分享」→「添加到主屏幕」
5. 打开后就是一个全屏课表，数据存在手机浏览器本地

> 说明：`file://` 打开的网页不能申请系统通知，也不能被浏览器判定为可安装 PWA；这是浏览器规则，不是课刻的问题。需要系统级提醒请用方案 C + 导出 `.ics`。

### 方案 B：局域网访问（同一 Wi-Fi）
1. 电脑双击 `启动课刻.cmd`
2. 看启动窗口打印的地址，例如：
   ```
   手机（同一 Wi-Fi）可以试试：
     http://192.168.1.23:8788/   (WLAN)
   ```
3. 手机浏览器打开这个地址
- 优点：手机和电脑看到的是**同一份服务的界面**（但数据各自独立，因为 localStorage 按设备分开）
- 限制：`http://` 局域网地址不是安全上下文，**不能安装 PWA、不能申请系统通知**

> 如果手机打不开：检查 Windows 防火墙是否拦截了 Node（第一次运行时通常会弹「允许访问」）；确认两台设备在同一网段。

### 方案 C：部署到 HTTPS（真正可安装 + 可收通知）
课刻是纯静态站点，整个 `class-tick` 文件夹丢到任意静态托管即可。

#### C-1 Netlify Drop（最简单，1 分钟）
1. 打开 <https://app.netlify.com/drop>
2. 把 `class-tick` 文件夹拖进去
3. 得到一个 `https://xxxx.netlify.app` 网址
4. 手机浏览器打开 → 「安装应用 / 添加到主屏幕」

#### C-2 GitHub Pages
1. 新建一个 GitHub 仓库
2. 上传 `class-tick` 里的所有文件（保持目录结构；不需要 `node_modules`）
3. 仓库 Settings → Pages → Source 选 `Deploy from a branch` → 分支 `main`、目录 `/ (root)` → Save
4. 等一两分钟，访问 `https://<用户名>.github.io/<仓库名>/`
5. 手机 / 电脑浏览器打开后即可安装

#### C-3 Vercel / Cloudflare Pages
新建项目 → 导入文件夹 / 连接仓库 → Framework 选「Other」→ Build Command 留空 → Output Directory 填 `.` → Deploy。

#### 部署后检查清单
- [ ] 打开网址能正常显示今日课表
- [ ] Chrome/Edge 地址栏出现「安装」图标
- [ ] 手机 Chrome 菜单里有「安装应用」
- [ ] `https` 下 `manifest.webmanifest`、`sw.js` 都能正常访问（DevTools → Application 面板）
- [ ] 断网后重新打开仍能显示课表（Service Worker 离线缓存）

### 手机提醒的可靠做法：导入 .ics 到系统日历
1. 课刻里导出 `.ics`
2. 传到手机
3. 用系统日历导入（iPhone：文件 App 打开 → 分享到日历；安卓：日历 App → 设置 → 导入）
4. 每个课程事件自带「课前 20 分钟」「课前 2 分钟签到」两个闹钟，**不依赖课刻是否打开**

## 四、常见问题

**Q：双击 cmd 一闪而过 / 提示找不到 Node**
A：先装 Node.js 20+，装完重开一次资源管理器或重启电脑。也可以在本目录手动执行 `node server.mjs` 看报错。

**Q：提示端口 8788 被占用**
A：说明课刻已经在跑了，直接打开 <http://127.0.0.1:8788/>；或双击 `课刻-停止服务.cmd` 后重试；或手动换端口 `node server.mjs 8789`。

**Q：通知不弹**
A：① 设置里看「系统通知」是否「已开启」；② Windows 设置 → 系统 → 通知，确认浏览器/课刻的通知没被关；③ 浏览器的「专注助手 / 勿扰」；
④ 打开页面时提醒才会触发（这是纯前端限制）；想要关闭也提醒 → 导出 `.ics` 给系统日历。

**Q：手机上显示的是旧的课表**
A：数据按浏览器本地存储区分。手机单文件版、电脑 localhost、部署的 https 域名，是**三个不同的存储空间**。用「导出 JSON / 导入课表」迁移。

**Q：换电脑了怎么办**
A：「课程」页 → 导出课表 JSON → 新电脑导入。

**Q：课表周次不对**
A：改「设置 → 学期信息 → 学期第一周周一」和「总周数」。

**Q：想要真正的电脑桌面小组件（不用窗口）**
A：Windows 桌面小组件（Widgets Board）需要打包的原生 provider；纯网页做不到。课刻用「应用窗口」达到相同效果，且更灵活（可以拖到任意位置、调整大小）。

## 五、卸载 / 清理

1. 双击 `课刻-取消开机自启.cmd`（如果设置过）
2. 双击 `课刻-停止服务.cmd`
3. 浏览器里卸载课刻应用（Edge：`edge://apps/`；Chrome：`chrome://apps/`）
4. 删除整个 `class-tick` 文件夹
5. 数据在浏览器里：打开课刻 → 设置 → 清空全部数据；或删除浏览器站点数据

## 后台传令（Web Push，可选）

```bash
npm install
node server.mjs
```

打开课刻 →「御前设置 → 后台传令 · Web Push」→ 开启。电脑关机或服务停止后推送停止；手机需要 HTTPS 域名，详见 [`web-push.md`](web-push.md)。

## 原生壳（Capacitor）

```bash
npm run native:prepare
npx cap sync android
npx cap open android
```

需要 Android Studio / JDK 17；详见 [`native.md`](native.md)。

## 安卓 APK

直接安装：[`dist/课刻-ClassTick-v1.6-Android.apk`](../dist/课刻-ClassTick-v1.6-Android.apk)（14 MB，自签名）。

1. 把 APK 传到手机（微信文件传输 / 数据线 / 网盘均可）
2. 用文件管理器打开 APK
3. 系统提示时允许「安装未知应用」
4. 安装后桌面出现「课刻 ClassTick」

注意：APK 是 Capacitor WebView 离线壳，后台 Web Push 在 WebView 内不可靠；需要关闭应用也提醒，请用 HTTPS PWA 或加原生通知插件。重建：`powershell -File tools/build_apk.ps1`。
