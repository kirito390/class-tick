# 课刻 ClassTick ·「城堡皇室」主题艺术指导

> 角色化落地（皇家导师艾莉丝、对话指令与素材管线）见 [`royal-tutor.md`](royal-tutor.md)。

> 本文件由 **Opus 5.5** 生成，作为「城堡皇室」主题改版的文案与视觉依据；落地实现见 `assets/royal.css` 与 `assets/app.js` 的文案层。

基调：纹章与王朝的庄重（权游）＋ 童话城堡的轻盈优雅（迪士尼）。皇家感只放在标题、装饰和语气里，时间、地点、课名、数字永远是第一信息层级。

### 2. 字体

| 用途 | 字体栈 | 说明 |
|---|---|---|
| 品牌字「课刻」 | `STXingkai, "华文行楷", STKaiti, serif` | 仅 Logo 与关于页大标题，≥ 22px |
| 页面标题 / Hero 课名 | `STSong, "华文宋体", "Songti SC", "Noto Serif SC", serif` | 字重 700，字距 0.04em |
| 日安语 / 空状态主句 | `STKaiti, "华文楷体", "Kaiti SC", serif` | 带书信语气，≥ 15px |
| 纹章家族名 / 蜡封印字 | `LiSu, "隶书", STSong, serif` | 只用于 1–2 字短词 |
| 正文 / 按钮 / 表单 / 导航 | `"Microsoft YaHei", "微软雅黑", "PingFang SC", system-ui, sans-serif` | 保证小字号清晰 |
| 倒计时与时间数字 | 同正文栈 + `font-variant-numeric: tabular-nums` | 数字不用书法体，防止跳动 |

手机端没有华文字体，栈尾必须落到系统宋体/楷体或无衬线；不打包字体文件。

### 4. 五条「不要做」

1. 不要大面积铺金色、渐变金或金属质感；金线只描边，不做文字色和按钮底。
2. 不要把时间、地点、课名、倒计时数字换成书法体或加描边/投影，行楷隶书只用于 1–2 处短标题。
3. 不要在课程格子、列表行里堆纹章花纹和纸纹背景；底纹透明度 ≤ 4%，信息区保持干净。
4. 不要用"陛下""臣""朕""奉天承运"这类称谓或古文腔，也不要血腥、战争、黑暗元素；语气是礼貌的童话宫廷，不是权谋剧台词。
5. 不要为了氛围牺牲可用性：对比度不低于 WCAG AA，动效（旗帜飘动、蜡封落下）≤ 300ms 且遵守 `prefers-reduced-motion`，点击区域不小于 44px。
